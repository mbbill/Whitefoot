Decision: A binding whose right-hand side reads a measure establishes the ordinary equality every copy of a tracked value establishes, and the fact system carries no rule of its own for binding a measure, because a measure is a read of a readonly field and so is a term like any other term the copy rule already relates, and a second rule publishing that same equality would be a second source for one fact, instead of a dedicated measure-binding fact standing beside the copy equality.

Decision: An admitted nonconstant integer multiplication's proved interval is published as an ordinary automatic fact on its value, because the checker had already computed that interval to discharge the multiplication's own domain obligation, and discarding it made a writer restate by hand what the checker had just proved, instead of keeping the interval as checker-internal state.

Decision: A range endpoint reaches the caller through the callee's ordinary requires and ensures, with Whitefoot body postconditions checked by FN-9 and linked definitions obligated to satisfy their declarations under SCOPE-3, using the same contract formation and caller result routes in both cases, because an operation-name family would create a second proof producer unrelated to the written callable boundary, instead of the system-range automatic fact or a claim that the checker verified a nonexistent Whitefoot body.

Decision: An admitted unsigned exact division over terms or constants publishes the quotient's bound for runtime divisors as well as literals, and an independently admitted exact product of the same quotient and divisor values publishes its bound by the captured dividend, because [runtime block decomposition](../../../research/investigations/compute-model/DESIGN.md#runtime-division-images) needs those elementary consequences of its actual arithmetic and they can be checked by finite value-image matching without nonlinear search, instead of limiting quotient facts to written literal divisors, requiring callers to supply an already-proved partition, or inserting tests for relations that must hold. The existing literal scaled image remains; ordinary product-domain discharge is still required.

Decision: A successful measure observation preserves the observed measure's current immutable affine image through its integer result and copies, because a merge's two ordinary length reads must still denote the two lengths constrained by its contract and fresh unrelated result atoms discard that identity before the fixed affine checker can use it, instead of requiring a separate equality proof for every copied measure or treating an old observation as a new measure after mutation.

Decision: At body entry, an established requirement ordering leaf with an admitted affine normalization but no L0 projection supplies that immutable affine inequality, using only the existing signed decomposition and retaining its exact requirement and truth sign, because [a recursive merge](../../../research/investigations/compute-model/DESIGN.md#binary-split-merge-pressure) must use its proved input-length sum to bound its output and discarding the already-admitted affine contract forces an inferior algorithm or a redundant runtime guard, instead of keeping composite requirements opaque, adding general nonlinear or path search, or duplicating L0 bounds to widen AUTO's premise combinations. Scalar replacement and measure kills retain their existing image semantics.
