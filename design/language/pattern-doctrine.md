Decision: The language teaches a closed catalog of program architectures instead of accommodating whatever architecture a writer brings, because a human language must let writers carry familiar patterns in or be rejected, while this language's writers are agents with no installed base to appease, so a closed catalog can be forced provided it stays complete, every task modelable, and efficient, blessed patterns hitting the fast paths, instead of an unconstrained architecture.

Decision: A restriction needs an accessible alternative and evidence about its authoring and runtime costs, and a gap in the catalog is a finding to investigate rather than authority to invent a rejection rule or force an unrelated architecture, because patterns alone cannot realize the writer objective and restrictions need usable alternatives, instead of a catalog used as enforcement.

Decision: A guidance restriction is revised when it excludes a better-performing implementation that meets the safety and development-feasibility requirements, because the constitution's performance objective outranks any particular guidance mechanism, instead of guidance that outlives its measured benefit.

Decision: The result of a trial in which a model writes programs under stated assistance describes only that model and that assistance and imposes no permanent authoring-cost or context ceiling on the language, because the main sacrifice behind performance and checked correctness is human authorship ergonomics and agents may write source humans would reject as inconvenient, instead of reading current writing difficulty as a language limit.
