Decision: A reusable Vector consumes a removed suffix synchronously through a monomorphized member in original order, preserving capacity and the retained prefix, by taking each first-half rear element into an owned local, exchanging it with the next suffix slot and consuming that local, then consuming the reversed remainder from the back, because the ordinary bounds and effect-overlap rules establish valid ownership and exclude callback observation of the backing, while the paired comparison in research/experiments/container-representation/vector-library/RESULTS.md establishes reduced large-record transfer cost with qualified independent stack groups and descriptor-before-transfer takes, instead of the separate suffix-reversal baseline, walking the retained prefix or allocating scratch storage. This selects the measured large-record benefit despite a short scalar reuse cost that remains to be attributed; it does not promise uniform speed across element types or optimizers. Movement remains O(removed) with constant auxiliary element storage; displaced rear elements still move, so this is not a minimum-transfer or universal native-parity claim.
