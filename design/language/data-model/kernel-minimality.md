Decision: The kernel admits, as a fourth compiler-owned generic declaration domain built the way the system domain is, only what a writer cannot implement in the language over the rest of the kernel, the typed but uninitialized run and the boundary that moves its window, because everything a writer can build on that primitive, growth policies, pools, keyed tables, swap, rebase, clear, truncation, or middle removal, belongs to a library or to user code and not to the specification, instead of a larger kernel inventory or ordinary prelude functions for those operations.
