Decision: Generics are monomorphization-only, expanded before IR from always-explicit type, const and function arguments with each inhabited instance checked as concrete code, because inference and bound solving add complexity and unpredictability to the trust path and the behavior witnesses need concrete direct calls, instead of inferred instantiation or dictionary-passing generics that share one runtime body across instances.

Decision: Function and nominal instantiation cycles must forward the complete argument vector unchanged in position and kind, including function arguments, even where a finite permutation cycle would be safe, because a growing recursive instance would not terminate and the syntactic cycle check decides that boundary without executing a search, instead of a more precise termination analysis or a depth, time or fuel limit.
