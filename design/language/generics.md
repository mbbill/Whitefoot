Decision: Generics are monomorphization-only, expanded before the IR from always-explicit type and const arguments with each instance checked as concrete code, and nothing in the trust path infers or solves bounds, because inference and bound solving in the trust path add complexity and unpredictability the checker does not need, instead of inferred instantiation or dictionary-passing generics that share one body across instances.

Decision: Polymorphic recursion is refused by a syntactic rule, every call inside a generic call cycle instantiating its callee at exactly the caller's own type parameters, even where a finite permutation cycle would be safe, because monomorphization needs a termination guarantee readable from the syntax, and a depth or fuel bound is barred by the rule that no acceptance depends on a budget, instead of a more precise termination analysis over parametric instantiation.
