Decision: Struct-of-arrays is the taught default layout for bulk data while array-of-structs stays a genuine need, served by a buffer of structs stored by value under ordinary ownership, because struct-of-arrays is usually the faster layout and the affine path already serves the record-by-record case without a copy-struct mechanism the language does not have, instead of forbidding array-of-structs.

Decision: Append-only stable identity is its own contract that pays no generation or recycling cost, and a recyclable stable identity, if the language ever admits one, is a separate contract rather than a cost every pool pays, because a well-typed slot-recycling use-after-free is unrepresentable when indices never recycle and access is then a bare bounds check, instead of one pool contract that pays for recycling everywhere.

Decision: Any operation that moves owners between slots, such as a compaction or a removal shift, is an ownership relocation in which every retained owner reaches exactly one destination and a moved-from slot is never read or dropped, because treating such a move as a metadata update or a copy would duplicate or lose owners, instead of metadata-only updates.

Decision: Full fixed arrays, initialized prefixes, and circular windows are distinct states, and placement and stable identity are separate axes with no mandatory handle or store indirection on dense values, because variable length and a head position are not universal array metadata and a fixed extent belongs to the type or state that has it, instead of one universal dynamic-array representation.

Decision: Source-function signatures keep their checked ownership and access modes independently of how parameters and results are represented, and those modes alone supply no loan origin, lifetime, or aliasing permission, because a representation choice must not widen or narrow what a signature promises, instead of deriving permissions from representation.

Decision: A nominal's region parameters are an axis of its identity at check time, two instances of one declaration that differ only in their region arguments being two checked types and one lowered representation, reconciled by a region-erased structural equality before lowering, because a region names a store for the proof and nothing at run time, so this lets a callee's formal-region instance and a caller's actual-region instance meet as one representation without monomorphizing every function over its regions, instead of erasing the region at instance lookup.

Decision: Bool is a two-variant prelude enum matched by the same tag-only mechanism as every user enum, and the primitive set is the fixed-width integers and floats of 8, 16, 32, and 64 bits with unit, because one mechanism then serves equality, match and if selection, and tag-width lowering for Bool and user enums alike, instead of a dedicated primitive boolean with its own literals and comparisons, or address-width and 128-bit integers.

Decision: A single store-resident value has its own compiler-owned cell type, Box, carrying no measure and formed by dedicated rows, because a one-element run costs three descriptor words against a cell's one pointer and would owe a nonempty-length proof at every read of a container the language already knows is never empty, instead of representing a boxed value as a run of capacity one.
