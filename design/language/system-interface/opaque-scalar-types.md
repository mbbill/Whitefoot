Decision: A value with no internal state that a program only constructs and passes whole, such as a command's exit status or a socket address, is its own opaque nominal type with a total pure constructor, because the language has no implicit conversion and every value's type is exactly what its producer fixes, so without a stated constructor the value would be unwritable, and a distinct type is what stops an arbitrary integer from serving as an exit status or an arbitrary integer group as an address, instead of a bare integer alias or a tuple of integers.
