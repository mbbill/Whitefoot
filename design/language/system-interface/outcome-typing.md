Decision: Each system operation declares its own outcome type, a two-outcome operation using the prelude Result and a wider one its own prefixed enum, because an exhaustive match with no wildcard arm would force dead hand-written arms at every call site for outcomes that operation can never return, and a shared union's variant list would turn each later operation into an edit of every existing call site, instead of one shared outcome union across the read, write, and copy operations.

Decision: An IoError class carries only fixed-size inline target detail, a native error code and a small origin discriminator that is copy data with no allocation and no release action, because every operation row is declared allocation-free and a richer payload would force a heap allocation effect onto every fallible system operation, instead of a heap-backed diagnostic payload carrying a host message or buffer.
