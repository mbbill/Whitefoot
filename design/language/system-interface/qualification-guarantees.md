Decision: A system operation's specification identity is target-independent, and a target qualifies for it only by supplying every guarantee that identity names, failing qualification and stopping compilation when it cannot, with no runtime negotiation and no implementation that narrows or emulates a missing guarantee, because a weakened operation would make the same source mean different things on different targets, and a negotiated or emulated capability would let target reality define the language in place of the specification, instead of runtime feature detection with dynamic dispatch, or emulating a missing facility such as directory-relative resolution by concatenating a path prefix.
