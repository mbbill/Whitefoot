Decision: A finite, program-recoverable capacity that several operations draw from is exposed as ordinary owned state, a factory an operation reserves a credit from through a short unique loan and a permit value that authorizes exactly one attempt and is handed back unspent on failure, with the factory's count never raised, because a hidden process-global pool would reintroduce mutation outside a function's arguments and let an overlapped schedule invent a resource-exhausted outcome the sequential program never produces, instead of a hidden runtime-global pool an operation consults directly, or an unconditional per-call exhaustion check with no reservation.
