Decision: A host string and the relative path built from one are an opaque inline lease, an address and a length carried by value that is neither a borrow nor a region-bearing type, with its backing kept alive by a target-qualification guarantee rather than a source-checked region, because reusing the region-carrying view machinery would make every argument-derived value unstorable under the storage rule, while the backing's lifetime is a target property that nothing in a program could check, instead of a region-bearing lease or an owned reference-counted backing with a release action.
