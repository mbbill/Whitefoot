Decision: An `affine_factor` written as a place whose trailing member names one of [MSR-1]'s four measures is admitted and denotes the measure term over the place below that member, and the place below it is resolved by the same indexed-place walker an executed measure read uses, because [INV-1] admits exactly "one `place` formed from an admitted measure place by one measure-member `psuffix`" and states that a subscript inside such a place is an ordinary [OP-4] occurrence judged where the relation is written, so the subscript's bound and the measured row must come from the walker that owns both, instead of refusing every suffixed place in a proof position, which was the retired reading where a measure was a call rather than a place form.

Decision: The walker that resolves an indexed place takes the lexical role of its root as a parameter, so a proof position resolves its root under that position's own use role while every other caller resolves an ordinary place base, because a `header_invariant` and a `use_premise` record their root identifiers under proof roles that the ordinary place-base lookup does not match, instead of giving the proof positions a second place walker, which would leave the subscript obligation and the measured row to drift from the read the program executes.

Decision: A counted loop whose body reaches the backedge without the walk retaining the header binder's affine image withholds the hidden increment and fails every next-header target, rather than stopping the compiler, because [OWN-8] makes rejection the answer wherever the checker cannot prove conformance and the withheld batch removes the loop's exhaustion authority without admitting anything, instead of asserting the image is present, which aborts the process on a program the language has a verdict for.

Rejected:
- Admitting a measure place whose root is written under a `deref` as an affine factor: rejected because [INV-1] says a measure place's root "names a live own-mode value of measured type", which a reference variable is not.
