Node: language/ownership/reference-rebinding

Decision: A reference variable may be rebound, and at a control-flow join it names the set of paths its incoming edges gave it, with every check on it required to hold for every member of that set, because a reference is a local name for a path and not storage of its own, so a merge is checked by repeating each ordinary path check over a finite set instead of retyping a holder, and because this node is new and carries the successor of the retired decision in language/ownership/no-reborrow that a borrow holder binds once and never retargets at a merge, instead of one immutable resolved root per holder that binds once and never retargets.

Decision: A path has a static shape: a loop-carried rebinding may change the index values inside a path and may never extend the path through the reference itself, because a self-extending rebinding has no finite target set at the join after an unbounded number of iterations, while a runtime index inside a fixed-shape path costs one proved bound, and a program that must walk a linked structure recurses over owned links or keeps its nodes in one storage and iterates an index at the same load count, instead of admitting runtime path depth with a conservative approximation of everything below the root.

Decision: A reference reaches a callee as an ordinary argument, with no child form, no suspension of the argument's source, no permission marker, and no region, because the callee's declared effect row lists what it reads and writes through each reference parameter and the call site compares the substituted paths pairwise, which is the whole of what the caller must know, and because this decision carries the successor of the reborrow family retired in language/ownership/no-reborrow, which under candidate x1 is no mechanism at all, handing a reference to a callee being an ordinary argument, instead of an admitted family of reborrow forms each with its own strength, endpoint, and suspension rule.

Rejected:
- A permission marker on a reference (`&uniq`, `&mut`, or any other) selecting whether the callee may write through it: rejected because the effect row already states every write, and a second spelling of one fact can disagree with the first.
- A block-scoped reference form or a lexical region confining a reference's extent: rejected because validity is a fact established at formation and invalidated by named events, a write, move, replacement, or release of a proper prefix, the end of the root local's scope, or the loss of a refinement fact a payload step depends on, and a lexical container adds nothing that fact does not already carry.
- A rebinding that extends the reference's own path on each iteration, for walking an owned linked structure by reference: rejected because after k iterations the path is k steps long, so the join has no finite target set; recursion or a pool index performs the same loads.
