Node: language/data-model/value-semantics

Decision: Every struct, enum, tuple, storage shape, heap cell, and generic instantiation holds only owned values, recursively and closed under wrapping, so there is no field, variant payload, or type argument through which a reference can be stored in a value, because a value that contains no interior pointer can be relocated by copying its bytes, which is what makes a window shift, a reallocation, and a move ordinary block copies rather than pointer-fixing operations, and because this node is new, owning the closure property candidate x1 Rule 1 states, that no aggregate ever contains a reference, recursively and under every wrapper, together with the relocation consequence Rule 1 draws from it, which no live node carries, the parent `language/data-model` assuming owned elements without stating that owned-only is closed under wrapping and generics, while the same closure property is also proposed as the first decision of a node under the ownership subtree although it belongs in exactly one node, the recommendation here being the data model because the property is a restriction on what a type may contain and is what makes byte-copy relocation of stored values sound, so that if the owner places it in ownership instead this node is withdrawn entirely, and because the companion half of the same idea, that a reference is a local name which is never returned, captured into anything that escapes, or otherwise made to outlive its function, which is candidate x1 Rule 4, belongs to the reference and ownership subtree rather than to the data model and is not proposed here, instead of admitting reference-typed fields, reference variant payloads, or references supplied as type arguments.

Rejected:
- A reference stored in a struct field or a variant payload, or supplied as a type argument such as an optional reference: rejected because relocating the containing value would then have to find and rewrite its interior pointers, so no move, growth, or window shift could remain a copy of bytes.
- Allowing the restriction only at the outermost level, with wrappers free to carry references: rejected because one generic wrapper would reintroduce stored references everywhere a wrapped value can be stored, which is every place a value can be stored.
