Decision: A `psuffix` names a measure or a window part only where the type of the place it follows has one, and is an ordinary field selection everywhere else, because x1 deletes the eight-name reservation and states that the window parts are "selected by the window type of the place they follow" and "occupy no declaration domain and reserve nothing", so a source struct may declare fields spelled `len` and `next` and a spelling alone can no longer decide the meaning, instead of keeping the spelling-directed test, which refused a writer's own field as a pseudo-field and refused the declaration that declared it.

Decision: A measure spelling over a place the measure table gives no row falls through to the ordinary field walk rather than reporting a type mismatch against "a measured place", because the spelling is now free and the place may be an ordinary struct, while a measure spelling over a place whose row answers *absent* keeps the mismatch, because there the type does select the measure vocabulary and the row is what denies that cell, instead of one rejection for both, which cannot tell a writer's `Node` with a `len` field from an `Array` asked for a `cap` the table removed.

Decision: The routing that sends a trailing measure spelling to the explicit-place resolver stays spelling-directed, because that resolver now owns the ordinary field walk as well, so a misrouted ordinary field resolves there identically, instead of making the route type-directed, which needs the base's type before the place is resolved and would duplicate the walk to obtain it.

Rejected:
- Materializing the prelude's declared `len`, `cap` and `head` fields into the storage shapes' checked types so that one field walk answers both: rejected because [MSR-2] supports a measure term with the measured place's own descriptor storage and with the one word the term names, which a field's storage does not model, and because [MSR-1]'s table, not the declaration, is what gives a cell its *exact*, *bounded* or *absent* class.
