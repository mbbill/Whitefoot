Decision: Workers own fixed-capacity offer deques, idle threads steal the oldest task, and a join that observes a pending target reclaims or executes local offers before stealing or waiting, because local publication avoids a contended lane scan and handshake on every offer, instead of a shared lane array; a join whose target is older than a retained offer can execute that newer offer before returning the target's result.

Decision: A join acquires its target's completion state before taking local work and returns if it observes DONE, because the [completion-order probe](../../research/investigations/compute-model/DESIGN.md#initial-completion-observation) demonstrates avoidable execution of a newer independent call before a completed predecessor releases following source work, instead of unconditionally popping before checking completion. A pending observation still permits ordinary-stack helping, so completion after the check can wait for a helper that has already started.

Decision: Ordinary groups and each bridge's retirement set join newest-published-first, while a proved bridge may retain its newer tail across retirement of older members, because the [bounded bridge trial](../../research/investigations/compute-model/DESIGN.md#bounded-call-group-bridge-trial) needs an earlier result before the next statement's arguments without completing every independent call, instead of imposing the whole-group join on that permitted boundary. This provisional selection preserves current-stack helping and requires observed useful overlap; it grants no ready-continuation or critical-path guarantee, because an owner executing newer work inline cannot resume its continuation when an older target completes.
