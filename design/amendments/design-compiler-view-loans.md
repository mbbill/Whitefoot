Node: compiler/view-loans

Decision: This node is retired, its file deleted and its subject passing to compiler/checker-facts, because its one decision carries a continuing view loan identified by a protected place, a region, a strength and a parent holder, and this language has none of those four: a reference is a local name for a path with no permission marker and no region [REF-1], it is not storage and so has no holder, and what the checker must carry is not a loan that continues but a path together with the ordinary validity fact [REF-2] that any write to a proper prefix ends.

Rejected:
- Retired decision, the checker carries the identity of a continuing view loan separately from its possible storage origins, retaining its protected place, region, strength and parent holder through ordinary copies and results: rejected because every component of that identity is abolished, a reference carrying no strength, no region and no holder, while the question the decision existed to answer, what survives a copy of a reference name, a control-flow join and a call, is answered instead by the resolved path and its validity fact in compiler/checker-facts.
- Retired refusal, reconstructing continuing loans only from local view formations: rejected because the hazard it named, an incoming exclusive view with a live shared child moved onward as though that child did not exist, cannot arise where no reference is exclusive and no reference has a child loan, while the parameter case it protected is now ordinary, a reference parameter naming the actual argument's path by substitution [EFF-5].
