Decision: Automatic derivation is a fixed set of terminating families that run to completion, and a harder proof is a finite explicit certificate the checker verifies without rediscovering it, because acceptance must never depend on solver state, a timeout, machine speed, or a work budget, and candidate x1 Rule 11 keeps exactly the existing fact forms, namely affine comparisons over measures and integer values, refinement facts from a dominating branch or a match arm, loop-header invariants, explicit use steps inside an invariant, and callee contracts, so this decision is kept as it stands, instead of SMT-backed acceptance.

Decision: Required partial-operation domains are established only by the specification's deterministic proof system, whose facts come from admitted types and declarations, selected control-flow edges, verified contracts, and checked invariants, because candidate x1 Rule 11 keeps those same sources of facts and Rule 7 keeps the third element of the same picture, that an index must be proved in bounds and that where the proof is unavailable the program tests the measure and reads the fact off the branch with no trap, so this decision is kept as it stands, while one obligation is left open for the owner and is not resolved here, namely that candidate x1 Rule 6's in-place update, in which a place's value enters a function and the function's result is committed to the same place, requires that function to be total and its row not to write, move out of, or free any prefix of the place, and although the row condition is an ordinary effect check, x1 does not say how totality is established and this subtree carries no decision that admits a totality obligation, so whether totality becomes a new obligation class discharged by the fixed families or is carried by the operation's own restrictions on what may appear in such a function awaits the owner, instead of writer assertions.

Decision: A nonempty explicit certificate is rejected when the automatic families already prove its target, because the boundary between automatic and written proof must be decidable from the language rules rather than by probing the compiler, and this redundancy rule is outside candidate x1, which says nothing about it, so it is kept as it stands, instead of tolerating redundant certificates.

Decision: A proof_use certificate holds at most 4096 entries and one invariant's affine formation at most 4096 scheduled expression nodes, input terms, and result terms, each a structural ceiling on the source and never a work or time budget, because the specification must name a number and this one is arbitrary, and the two structural ceilings are outside candidate x1, which says nothing about them, so they are kept as they stand, instead of no structural ceiling or one fixed by a machine's capacity.

Decision: The fact language carries no quantified fact over the elements of a storage and no per-slot occupancy fact, because what a program's occupancy depends on is stored as data and read back through one bounded index, and this limit, which candidate x1 Rule 11 states for array elements and per-slot occupancy, adding that occupancy determined by data is stored as data, and which Rule 12 carries to control-flow joins by keeping occupancy in ordinary tag or option storage, is carried by no live node in this subtree although it is the boundary that keeps the automatic families terminating over storage, instead of quantified element invariants that the automatic families would have to instantiate at every read and re-establish at every write.

Decision: The disjointness that the access rules require, that two indexed or ranged positions on one storage name different storage, is discharged by the same fixed automatic families and written proof steps as every other obligation, and a pair left undischarged counts as overlapping, because admitting an access on an unproved distinctness would rest memory safety and overlap permission on how far a checker happened to reach, and because candidate x1 Rule 3, which judges path prefixes and overlap conservatively so that two indexed positions on one storage count as overlapping unless their indices or ranges are proved distinct, Rule 10, which rejects a call whose substituted effects overlap on an unproved pair, and Rule 13, which admits overlapped execution of two adjacent statements only under that same judgment, all consume proofs of distinctness without saying where they come from, so this node states that those proofs come from the ordinary fixed families and written steps and from nothing else, while the overlap relation itself, which paths are prefixes of which and what a write to a prefix invalidates, belongs to the reference and ownership subtree and this node owns only the discharge, instead of a separate alias analysis or a solver consulted only for index disjointness.

Rejected:
- Tolerating an unused explicit certificate as advice rather than an error: rejected because the redundancy rule ties the writer's choice to the exact language version instead of to compiler behavior.
- Limiting the explicit certificate language to what the automatic families can already prove: rejected because a certificate that can only restate an automatic proof adds no proof, so the certificate language must reach beyond the automatic families.
- Quantified invariants over the elements of a storage: rejected because every write into the storage would owe the quantified fact again, and establishing it would require a derivation over elements that no terminating fixed family performs.
