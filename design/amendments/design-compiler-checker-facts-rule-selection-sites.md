Decision: An element target reached through a reference is refused by [SET-1] at the target place when the enclosing callable's declared row carries no `writes` of that element's own path, and the question is asked of the complete element path rather than of the base the subscript selects from, because [SET-1] makes a target writable when it "is `deref(p)` or a path below it where `p` is a reference parameter whose declared row carries `writes` of that path", and a row may name the element and not the whole -- `writes(slots[at])` is an ordinary [EFF-1] path -- so testing the base would refuse exactly the rows that authorize the write; without the test at all the write went through and the mismatch surfaced as [EFF-2]'s row comparison, which [EFF-2] itself forbids by saying "a write is admitted only where ordinary ownership already admits it [SET-1]", instead of leaving the refusal to the row comparison, which reports the wrong rule and, for a body whose row happened to cover the write, would report nothing.

Decision: A measure member written after a subscript, `rows[0_u64].len`, is resolved as a measure read over the storage place the subscript selects, rather than as a field selection on the element type, because [MSR-1] admits a measured place "formed with any number of field-selection and enum-payload `psuffix`es, `deref` wrappings, and subscripts" and [ENT-2] clause (b) makes the result a term; resolving it as a field step reported [TYPE-5] against the element's own type, which declares no such field, instead of adding a measure step to the resolved storage path, which would make a measure select storage below itself and [MSR-1] gives it none.

Decision: An undischarged `free_empty` requirement cites [OP-14] and renders its residual, rather than the [FN-8] call-requirement diagnostic, because [OP-14] states the site and the restructuring for its own obligation, and the clause reaches the checker on the ordinary call-requirement path only because the row is a [PRE-1] record.

Decision: A `move` of a window slot or an array element cites [WIN-3] with the restructuring `use take_back, remove_at, or swap`, rather than [TYPE-2] with the retired `replace` statement, because [WIN-3] states that refusal and its restructuring in one sentence and the statement it named no longer exists; [DIAG-1]'s first-defined ordering gives the event to the rule the spelling violates, and the liveness judgment still owns a later read of a dead root.

Decision: A scrutinee written as an operation over two atoms is a non-place scrutinee whatever its first atom spells, because [GRAM-5] writes `expr := atom infix_tail? | call` and [OWN-13] asks its ownership question of a place; reading the leading atom of `match deref(p) +checked 1_i32 { .. }` as a dereferenced place made the checker demand a resolved place the operation's value does not have and stop with an internal failure, instead of inspecting the checked value's shape, which cannot distinguish a moved temporary from the place it was read out of.
