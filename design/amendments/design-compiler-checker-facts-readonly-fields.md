Decision: A checked field carries a `readonly` flag taken from the written modifier, and a write target is refused by walking the target's own suffix run against the type of the place each suffix follows, because x1's [TYPE-2] makes the modifier a property of one field of one declaration and refuses "a path that ends at or passes through a readonly field", so the refusal needs the declaration reached at each step and not only the target's final type, instead of deriving unassignability from the target's selected type, which cannot distinguish `set f.header.version` from `set f.size` when both end in an assignable `u64`.

Decision: The refusal is sited at the complete target `place` and carries the field's own spelling, because [TYPE-2] states the error "at the complete target `place` or argument `atom`" with the restructuring `use the operation that changes it, or replace the whole value`, and a writer reading it needs to know which step of the path was readonly, instead of siting it at the suffix, which reads as a rejection of that member rather than of the assignment.

Decision: A measure of a measured place is refused as a readonly-field write and not as a struct-field mismatch, although the measure is no field of any checked nominal, because x1 declares `len`, `cap` and `head` as readonly fields of the prelude's storage shapes while the checker still reads a measure through [MSR-1]'s table rather than through those declarations, so the refusal has to recognize the measure by its table row to cite the rule the writer's source is judged by, instead of materializing the three declared fields into the shapes' checked types, which would give a measure the field's storage as its support where [MSR-2] gives it the measured place's.

Decision: The argument half of the refusal reads the written `borrow_expr`'s place syntactically, from the argument `atom`, and only for a base that is a bare binding, because [TYPE-2] names the argument `atom` as the site and the readonly modifier belongs to the declaration the path walks through rather than to the reference's referent type, instead of judging the substituted effect row's resolved places, which carry field ordinals without the declarations that own them.

Rejected:
- Refusing every write whose target type is reached through any readonly field anywhere in the program: rejected because [TYPE-2] refuses a *path*, and a whole-value assignment that replaces the owner is admitted by the same rule, so the test has to be over the written steps.
- Leaving the measure write target on [TYPE-10]: rejected because x1 rewrites that rule to the window parts alone and routes a measure write to [TYPE-2], and the conformance corpus names the new rule in `type2-neg-readonly-measure-write-target`.
