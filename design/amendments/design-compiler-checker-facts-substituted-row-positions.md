Decision: An index or range position of a declared effect row is replaced at the call by the value its own argument carries, so `writes(slots[at])` called with the literal one writes the element place `slots[1]`, because [EFF-1] admits such a position only as a value parameter of the same callable and [EFF-5] substitutes the actual for the formal, which is what lets [OWN-7] separate that write from a live reference to a different literal element; reading every substituted position as the unknown offset instead made one call's declared element write reach every element of the base, instead of leaving the position unknown, which is conservative for the kill but denies the separation the rule grants.

Decision: Every substituted position of one call shares one reserved capture identity, distinct from the identities a written `psuffix` mints and from the unknown offset, because [REF-1] names a captured value by the occurrence it was evaluated at and a substituted position has no occurrence of its own to be named by; two positions that identity alone cannot tell apart are then read as one storage, which is the conservative direction for a kill, while two written literals are still separated by the value beside the identity, instead of minting a fresh identity per position, which the kill collector has no counter to allocate from.

Decision: An argument that is not a written literal, a named integer const, an in-scope const generic, or a live binding read leaves its position unknown, because those are exactly the forms [MSR-1] admits as an offset a place relation can name, instead of inventing a term for an arbitrary argument expression, which would relate two element places no admitted family can decide.
