Decision: The structural checker publishes the resolved paths established for each reference holder during its final body traversal as a function-wide origin inventory, and place summaries consume those paths without another origin fixed point or recursive holder lookup, because incoming parameter roots name entry storage even after the parameter is rebound and replaying straight-line assignments as path equations can invent unbounded recursive descent, instead of reconstructing origins from checked expression spellings or imposing a reference-expansion depth limit. Formation, delivery, payload binding, rebinding and settled loop headers contribute every alternative; function retries discard the preceding inventory. This inventory remains an over-approximation for the existing consumers, not point-current proof authority. research/investigations/consistency-followups/DESIGN.md records the source counterexamples and validation criteria.
