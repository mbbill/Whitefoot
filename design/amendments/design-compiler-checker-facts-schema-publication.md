Decision: The symbolic schema pass, which checks each generic template's own body once against symbolic arguments, seeds its reachable-instance walk with the canonical symbolic instance of every generic template, because the walk that decides which instances receive [FN-9] selectors starts at the nongeneric signatures and follows their calls, and no nongeneric signature reaches a generic body, so a call a generic body makes  --  every [PRE-1] construction record among them  --  contributed no selector and its declared `ensures` was published to no generic body at all; the same pass also admits a callee substitution that is still symbolic when the caller's own substitution is symbolic, because a schema caller forms no concrete substitution and the concrete requirement exists to exclude an instance materialized from an incomplete [FN-2] call, instead of leaving the schema pass with the concrete pass's universe, which made every window proof inside a generic function start with no length fact.

Decision: A schema instance's clauses are admitted as schema clauses at that admission too, so the selector is built with the symbolic-substitution reading rather than the concrete one, because its type arguments are symbolic and the clause typing that needs a concrete [FN-2] substitution waits for a concrete instance, instead of admitting it as concrete, which turned an ordinary symbolic instance into a compiler invariant failure.

Decision: An unrouted clause of a schema instance is admitted when its result ordinal is a measured type [MSR-1] named as a measure member and nowhere else, as well as when the ordinal is a fragment integer or the clause names only exclusive exit state, because [FN-9] states exactly those two admitted unrouted shapes and every [MSR-1] measure is u64 whatever the element type is, so such a clause is already inside the concrete integer fragment and the symbolic type argument reaches none of it, instead of admitting the integer-result shape alone, which silently dropped `ensures result.len == 0_u64` from every construction record.

Decision: A [PRE-1] row carrying a compiler-owned window type parameter has its clauses judged as soon as an operand supplies a shape that is one of [MSR-1]'s measured types, and only the unsubstituted parameter of the symbolic schema instance leaves them unjudged, because [OP-10] says the operand supplies W and `deref(window).len` then names a measure of a measured type whatever that shape's element type and capacity still are; keying the refusal on the argument not being concrete instead withheld the judgment from every operand-directed instance selected inside a generic body, instead of judging the row against the unsubstituted parameter, which is no measured type and has no measures to name.

Decision: A schema instance keeps the selector of a clause whose result ordinal has an unbounded symbolic type, and the schema builder alone decides which of its clauses are admitted, because [FN-9] admits a clause naming only exclusive exit state whatever the result type is and such a clause supplies no result datum at all, so `take_back`, whose result ordinal is the operand's element type, still publishes the length it carries across the call; dropping the selector on the result type alone withheld every clause of that row from every generic body, instead of keeping the drop, which was written for clause typing that only the concrete instance can do.

Decision: A clause's own projections below a result ordinal continue the destination's path at the caller, so `ensures result.inner.len == 0_u64` names the measure of the cell content the binder holds, because [TYPE-9] makes a `Box`'s content its member `inner` and [CALL-4] makes the binder the place a measure over that ordinal is taken over; dropping the clause's projections read the relation over the cell itself, which has no [MSR-1] row at all, so every boxed construction record published nothing, instead of instantiating the relation over the destination's bare place.
