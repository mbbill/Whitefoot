Decision: A range formation `&x[lo..hi]` [REF-4] carries the pair of captured endpoint values it minted into the checked tree, and the flow walk publishes each endpoint's affine image against the occurrence that evaluated it, because the pending compiler/checker-facts call-separations decision hands [OWN-7]'s range orderings to the flow as substituted-path pairs, and the only thing those pairs carry is the range *step* -- two capture occurrences -- so a discharge needs a way back from an occurrence to the two values that formed it; the formation is the one point where both endpoints are live and already evaluated, instead of re-reading the endpoint spellings at the call, which would compare whatever the bindings hold there rather than the immutable values the formation captured.

Decision: The published image is keyed by the start endpoint's capture occurrence alone, because that occurrence is minted from the offset atom's syntax node and is therefore one-to-one with the formation [REF-1], so one formation has one key and two formations never collide, instead of keying by the complete resolved place, which changes with the actual spelling at each argument, or by the pair of endpoints, which would need two lookups to answer one ordering.

Decision: A pair is discharged when the closed affine state proves any one of `first.end <= second.start`, `second.end <= first.start`, `first.end <= first.start`, or `second.end <= second.start`, because [OWN-7]'s two range steps separate when one ends before the other starts or either is empty, and a formation already discharged `lo <= hi` [REF-4], so an empty range is exactly the degenerate ordering on its own endpoints, instead of a dedicated emptiness predicate, which would be a second reading of the same two terms.

Rejected:
- Leaving the flow's range-image map unpopulated and reporting every range pair as `UndischargedRangeSeparation`: rejected because the family then refuses two literal-disjoint arguments `&a[0_u64..4_u64]` and `&a[4_u64..8_u64]` at one call, which [OWN-7] separates and [EFF-5] therefore admits, so the compiler would refuse a program the language accepts.
- Recovering the endpoints from the substituted path's captured terms instead of from the formation: rejected because a captured term is a literal, a binding read, a const, or opaque, and only the first and third of those name a value; a binding endpoint would lose its image exactly where the affine state has one.
