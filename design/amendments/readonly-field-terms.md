Node: language/checks-and-proofs

Decision: A place reached through one or more subscripts is a term of the fact language exactly when its last step selects a readonly integer field, prelude measure or writer-declared alike, and each offset is itself a tracked place or a constant, because such a field changes only through a write to a place containing it and such an offset only through a write to its own support, so the ordinary overlap kill ends every fact about the term, instead of admitting every subscripted integer place, whose facts die at almost every element write not proved distinct, or only the prelude's measures. It replaces the node's decision beginning "A place reached through one or more subscripts is a term of the fact language", whose ground covered only the measures; the [readonly-field term investigation](../../research/investigations/readonly-field-terms/DESIGN.md#soundness-every-change-is-an-overlapping-write) lists the killing events, the offset rule and the evidence.

Rejected:
- Admitting only the prelude's measures below a subscript: rejected because a writer's readonly field changes by exactly the events that change a measure, so the restriction is a special case with no soundness difference, and an index-based structure such as an arena tree could state no relation about one element's field in a requirement and could not bound a loop by it.
- Relying on a let-bound copy of the field instead of a term: rejected because a copy is detached from the storage it was read from, so a requirement cannot relate an element's field to another storage and a caller's fact about the element cannot reach the callee.
- Admitting any offset and reporting an unrepresentable one as a compiler limit: rejected because an offset whose changes no term records as support, such as an element read, lets the place come to select another element with no kill, so the restriction is a language rule, while an admitted offset a compiler cannot capture remains a compiler capability.
