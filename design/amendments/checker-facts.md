Decision: Measure terms and goals share typed descriptor-word support and the ordinary resolved-place overlap machinery for kills, because independently approximating goal support can retain an obsolete length beside a new one and falsely discharge later obligations by contradiction. The typed member walk selects the three measure names and four window parts only for a type that owns that vocabulary; unrelated fields retain their declaration identity and readonly provenance through aliases. Terms over named offsets use canonical current-place identity and depend on those bindings, while captured separation uses evaluation identity; literals and constants use their value and opaque offsets retain occurrence identity, instead of one identity relation that either splits a repeated term or equates references formed across a write. An offset a reference captured from a binding is named by it only until a write of that binding reaches the reference, on any path including a loop's backedge; from then on the offset retains its occurrence identity and depends on no binding, and a call passing the reference still instantiates at its resolved referent, because the binding's spelling then names another value while the reference still selects the storage it captured (REF-1), instead of instantiating that call at the reference holder.

Rejected:
- Instantiating a call at the reference holder once an offset of its resolved referent is no longer named: rejected because FN-8 and ENT-2 instantiate a reference formal at its resolved referent, and a guard written through the holder would then prove the call's requirement only after the index binding was written, while the same guard stays refused when it is not.
