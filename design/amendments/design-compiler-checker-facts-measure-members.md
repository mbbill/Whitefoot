Decision: A written storage-shape place may end at the declared readonly field `.len`, `.cap` or `.head`, selected by that place's trusted measured shape and retained as the measure read over everything before the suffix; `deref(part).len` is the corresponding compiler-known range-reference case with no declaration [OP-15, REF-4]. There is no `.room` measure. A suffix below the selected `u64` is rejected by ordinary typed-place formation, instead of treating measure spellings as globally reserved pseudo-fields or accepting a measure row the selected shape does not have.

Decision: [TYPE-10]'s refusal is sited at every attempted value use of the four window parts `next`, `last`, `filled` and `free`; measure reads are ordinary readonly-field reads admitted by [OP-15], and attempted writes to `len`, `cap` or `head` are the ordinary [TYPE-2] readonly-field refusal, because only a window type gives the four part names their declaration-free role while other types may declare fields with the same spellings, instead of refusing the same spelling on an unrelated user field or treating window parts as readable storage.

Decision: A `Box` result whose content the measure table gives a row is an admitted [FN-9] selector datum, and a selector atom that reads a measure stands for a `u64` whatever its measured place's own type is, because [MSR-1] admits a measure place formed with field-selection steps and [TYPE-9] reaches a `Box`'s content by exactly one such step, `b.inner`, which is how every boxed construction record states its own `ensures`, instead of admitting only a result whose own declared type the measure table gives a row.

Rejected:
- Giving a measure a second field identity in a compiler-synthesized descriptor struct: rejected because `len`, `cap` and `head` are already the prelude storage shapes' declared readonly fields, while range `len` is the one compiler-known exception [OP-15, REF-4], so an invented field would duplicate their source identity and move proof support from the measured place to synthetic field storage contrary to [MSR-2]. The declaration-free [TYPE-10] names are only the four window parts `next`, `last`, `filled` and `free`, which are not measures.
