Decision: A `deref` step over a reference parameter contributes one leading projection to the declaration-boundary contract template and no step at all to the same clause read inside the callee body, because a caller substitutes the actual argument's own path for the formal and consumes exactly that leading projection, while [REF-1] makes the parameter name the path itself inside the body, so one spelling has two readings and the body reading must equal the identity every other term over `deref(p)` already carries  -  the obligation an `deref(p)[i]` subscript owes synthesizes no `deref` step  -  instead of dropping the projection from the template, which leaves the caller-side substitution with nothing to consume, or synthesizing the step at every body term, which would reintroduce the retired holder-dereference spelling the resolved-root rule replaced.

Decision: A `borrow_expr` whose place is written under a `deref` of a reference variable is rooted at that variable and carries only the steps written below it, exactly as the same place written without the step is, because [REF-1] replaces a `deref` step with the path the reference names, so `&deref(p)[i]` and the reference-rooted form name one place and one representation, instead of refusing the `deref` spelling in a `borrow_expr`, which would leave the spelling [REF-1] requires unusable in the one position [OP-10] and [OP-11] write it.

Decision: A `match` whose scrutinee is written under a `deref`, or as a `borrow_expr`, is a reference-mode match whose payload binders are references naming the scrutinee path extended by their payload step, while a bare reference variable written as a scrutinee stays the [TYPE-7] missing dereference, because [OWN-13] distinguishes matching a place of own mode from matching through a reference and [REF-1] says the storage a reference names is reached only through `deref`, so the written step is what separates the two, instead of reading the mode off the scrutinee expression alone, which makes `deref(p)` an own-mode match and moves a referent the function does not own.

Decision: A `Box` scrutinee, a `Box` subscript base, a `Box` propagate operand and a `Box` returned where its content is the declared result are each the ordinary wrong-operand rejection of the rule that owns that position, and none is a missing dereference, because [TYPE-9] makes a `Box`'s content the ordinary field `inner` rather than a referent reached by `deref`, so the repair is the field step and not a `deref`, instead of keeping the retired implicit-holder-read judgment, which cited TYPE-7 and instructed a spelling the content step no longer has.

Decision: A `move` of a place written under a `deref` cites OWN-1, and [WIN-3]'s no-take refusal is reserved for a window slot or an array element, because [OWN-1] admits a consume only for "an affine or linear place rooted in a live own-mode binding" and a place under a `deref` is rooted at storage the function does not own, while [WIN-3] states its refusal for the element positions alone, instead of citing WIN-3 for both, which tells a writer to reach for `take_back`, `remove_at` or `swap` at a place no window operation can reach.

Decision: A `Box`'s member `inner` is admitted as an effect-path suffix and contributes the dereference step the content already is, because [TYPE-9] makes that member the content's ordinary field step and [OP-15] states that a measure read through a reference parameter exhibits the measure path below that parameter, so `deref(cell).inner.len` has the declared row `reads(cell.inner.len)` and no other spelling of it exists, instead of refusing the member as a field of a type with no declared fields, which leaves a boxed window's measure read with no writable row at all.

Rejected:
- Making the entailment synthesize a `deref` step for every term rooted at a reference binding, so the template's leading projection needs no body-side reading: rejected because the checker's own resolved places, which the same kill events and overlap judgments compare against, carry no such step, and adding it on one side alone would make a write through a reference miss the facts it must kill.
