Decision: The [PAR-1] and [PAR-2] judgments ask the [OWN-7] overlap relation with the unproved-separation oracle, so every index pair and every range pair that the fixed [ENT-6] families would separate answers "overlapping" inside the permission judgments, because permission runs over the finished checked program after the entailment flow has been discarded and holds no proof state of its own, and [OWN-7]'s own default for a pair no admitted family discharges is that it overlaps, so the answer is sound in the only direction permission may fail in — it loses overlap opportunities and can never grant one the rule refuses — instead of permission re-running the entailment fragment, which would put a second proof path outside the checked program, or reading a syntactic approximation of the separations, which would answer questions no rule authorizes it to answer.

Decision: Retaining the function's proved separations on the checked function, so that permission reads the same answers the call-site check [EFF-5] already proved, is the successor this decision expects, because the ledger of proved index distinctness, proved range disjointness and [WIN-2]'s conditional row is per-function data the entailment flow already builds, and carrying it forward costs one field where re-deriving it costs a second acceptance path [DIAG-2]; until it is carried, the two element families of [PAR-2] are what keeps counted permission reachable, because they consume retained [OP-4] and [REF-4] images rather than the overlap oracle.

Rejected:
- Giving permission its own separation search over the resolved paths: rejected because [DIAG-2] makes the checked program the only input that may grant lowering authority, and a search run after checking would establish a program property the checked program does not state.
- Answering an unproved index pair as separated on the ground that permission changes no source verdict: rejected because a granted overlap is emitted code; an unsound permission is a data race in the emitted program even though no source verdict moved.
