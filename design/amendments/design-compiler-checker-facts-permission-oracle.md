Decision: The [PAR-2] judgment and every [PAR-1] position outside the bounded retained range handoff ask the [OWN-7] overlap relation with the unproved-separation oracle, so an index pair and every range pair without exact pair-scoped evidence answers "overlapping", because [OWN-7]'s own default for a pair no admitted family discharges is that it overlaps and permission may lose an opportunity but may never grant an unsafe emitted overlap, instead of permission re-running entailment after checking or reading a syntactic approximation of a proof family.

Decision: For [PAR-1] range conflicts, the structural footprint planner records every exact `(first statement, second statement, captured-range pair)` question for every source-ordered pair in a candidate straight-line segment before entailment runs; the ordinary flow proves that question only in the state before the first statement, meets repeated visits with logical AND, fails closed when either capture has no image there, and retains each successful visit's ordinary derivation root. The retained node wraps the affine or contradiction parent with the complete captured-range pair and the selected one of [OWN-7]'s four orderings, so [DIAG-2] states the exact conclusion rather than rooting a targetless affine consequence. Permission then asks the free overlap relation with an oracle containing only that exact pair's retained answers and forms a run by comparing every new statement with every earlier member, because [PAR-1] fixes both the first-statement state and all-pairs composition, instead of reusing a function-wide separation ledger that has neither statement identity nor proof context and can leak a guarded, sibling, later or stale fact. The handoff is optional checked-program metadata under [DIAG-2]: failure changes no source verdict, creates no runtime edge and retains sequential lowering. General index mapping through the first statement's `ensures` remains unavailable rather than approximated.

Rejected:
- Applying a range's partition constraint when it is formed, before checking whether the body writes it: rejected because the reference-only model uses the projected effects to distinguish read-only input from output; the unchanged stencil floor requires overlapping input rows to stay eligible while differently mapped writes and reads of another iteration's output remain denied. The survey records the retained formation evidence, marks covering ranges reached by write footprints, then checks all accesses against those written origins. The criterion is recorded in research/investigations/range-loans/DESIGN.md.
- Giving permission its own separation search over the resolved paths: rejected because [DIAG-2] makes the checked program the only input that may grant lowering authority, and a search run after checking would establish a program property the checked program does not state.
- Reusing the function-wide [EFF-5] separation ledger: rejected because a proof is available only on dominated edges, so a true answer under one guard or at a later call can authorize a different statement pair whose first-point state does not prove it.
- Keeping the running union footprint for proof-carrying ranges: rejected because the union erases which earlier statement contributed an access, while the retained oracle is deliberately keyed by that exact ordered pair; direct comparisons against every earlier run member preserve the required context.
- Answering an unproved index pair as separated on the ground that permission changes no source verdict: rejected because a granted overlap is emitted code; an unsound permission is a data race in the emitted program even though no source verdict moved.
