Decision: 一个循环前事实会在循环头处存活下来，除非循环体内部有一次清除（kill）能够在不离开循环体的情况下到达之后的某个循环头，因此一次 return、一次被传播的错误，或一次 break，都不会在循环头处清除任何事实，因为退出作用域规则会在任何包含 return 的循环中丢弃全部循环前事实，并且这是导致 DEFLATE 解码器在其 29 处证明义务位点中只证出 5 处（而预期本应证出 17 处）的主要原因，而不是把每一条离开作用域的边都当作循环头处的一次清除。

Rejected:
- 每一条离开作用域的边，都会在循环头处清除每个绑定的事实：被否决，因为循环体内的一次 return 就会丢弃全部循环前事实，而同一个程序，当 return 在循环之外时能够履行证明义务，当 return 移到循环内部时却会被拒绝。
