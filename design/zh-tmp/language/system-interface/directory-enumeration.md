Decision: 目录枚举是一次性尝试，把一批数量有限、可移植的记录，转移到调用者已验证的 buffer 范围之中，同时推进目录自身的位置，句柄只拥有一个游标，不拥有任何存储，因为一个自己持有窗口的句柄，需要系统层并不分配的存储、需要再调用一次来把它排空，还需要一条针对它仍持有的条目的生命周期规则，而把结果转移到调用者范围的做法，则完整地重用了既有的、一次性尝试的文件读取契约，而不是采用一个句柄自持窗口、逐条产出条目的方式。

Decision: 一个被枚举出的名字，到达源码层面时只会是字节，代表自身和父目录的条目会被不加过滤地报告出来，并且不固定任何顺序，因为把一个名字变成主机字符串或路径值，将会重新引入一个路径模型，而固定的顺序则会许诺一些主机根本不提供的东西，而不是提供经过过滤、排序、以路径值表示的条目。

Rejected:
- 一个枚举句柄，自己持有一个内部窗口，逐条产出主机条目：被否决，因为它需要系统层并不分配的存储、需要再调用一次来把它排空，还需要一条针对所持有条目的生命周期规则。
