Temporary workspace for recovering past decisions into the design trees. It holds an index of the sources still available (commit messages, pull request descriptions, research records, the frozen memory tree), module-by-module audits of the compiler against the tree, and the candidate decisions extracted from those sources for the owner's triage. Sources only help the owner remember; every decision that enters a tree is the owner's, recorded through the ordinary procedure with a log entry naming where it was recovered from. This directory is deleted when the recovery is complete and is linked from nowhere.
