## Agent mechanics on this host (probably the same in the cloud)

- The Workflow runtime kills an agent after 180 s without a tool event and
  gives up after six kills. Every workflow prompt starts with: never pass a
  `timeout` to Bash (the default 120 s auto-backgrounds long commands);
  read `NOTES.md` and `git log -5` before acting; keep each Write/Edit
  under ~2 KB; build tables with shell scripts.
- Never run a recurring cron while workflows are in flight: each fire
  interrupts every mid-generation subagent.
- Never `SendMessage` a workflow agent by id (it spawns a duplicate);
  resume with `resumeFromRunId`; `TaskStop` before relaunching.
- Verifiers that spawn load generators must kill them; leftover spinners
  took the host to load 97 once. Stop docker containers when done; the
  Linux container needs `--security-opt seccomp=unconfined` for io_uring
  and TSan.
- Agents commit a WIP after every step; one worktree per agent.
