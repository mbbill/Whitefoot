# External distinctions and their dependants

Baseline: `20043721f68eff0c3bdda72762d8b5221473e600`, specification v0.57.
Paths and physical line numbers below refer to that revision, including blank
lines in module sizes. They do not refer to the paused, uncommitted D8 drafts.
The [design](DESIGN.md), [owner selections](DECISIONS.md),
[execution plan](EXECUTION.md), and [case register](CASES.md) use this inventory.

This is a dependency inventory, not a deletion count. A mixed module is not
external-only merely because it contains a system-call arm. Conversely,
ordinary Box/run tests now depend on owned-state routing even though their
source mentions no host object. Both are included. Frozen specifications,
historical research results, and alternative design records document past
behavior; removing a live mechanism does not authorize rewriting that history.

The census starts from tracked source, the active specification's declaration
domains, all manifest records, and the named routing/release/target types. It
follows their consumers through resolution, checked IR, entailment, permission,
lowering, code generation, driver diagnostics and executable harnesses.
Text searches include the SYS/HOST/PATH/QUAL rules, all current native callable
names, resource names, command entry forms, state/target summary identifiers,
and the gated boundary vocabulary. Search candidates that are ordinary math,
grammar terminals, source borrow suspension, or operating-system tooling are
identified as retained, rather than counted as semantic violations.

## Inventory totals and interpretation

SYS-2 currently owns 30 nominals (15 opaque, one struct, 14 enums), 52 variants,
82 variant fields, two struct fields, 29 functions, 31 declared operation loan
regions and 81 value parameters: 307 declaration records
(`spec/kernel-spec.md:2887`). SYS-5 adds 15 native leaf release rows. The
prelude currently has 24 records; those are ordinary declarations to retain,
not 24 more external mechanisms. PRE-1's ordinal count and all derived
diagnostic data must change together when declarations are moved.

The conformance manifest has 779 cases and 32 non-case coverage records;
754 case sources contain a line beginning `command fn main(`; 773 contain
the word `command` somewhere, including docs and deliberately malformed input.
Seventy-five cases directly cite
SYS/HOST/PATH/QUAL rules; these overlap the entry population. The case register
also includes ordinary FN-1/FN-4 routing and entry-rule cases with no SYS tag.
These counts must not be summed to estimate work.
