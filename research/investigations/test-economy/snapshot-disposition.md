# Snapshot case disposition

The source of each decision is the actual program at revision `66eeb45a`, not
its historical finder comment or the verdict recorded by that compiler.
For a deleted source, `git show 66eeb45a:tests/snapshot/cases/<family>/<id>.wf`
retrieves the exact input reviewed here. The [active specification](../../../spec/kernel-spec.md)
owns every normative expectation. This record is the technical ground for
the corpus retirement described in [the redesign](redesign.md).

Admission follows the observation: language requirements belong in conformance;
program outputs belong in programs; proof records, lowered state and runtime
implementation obligations belong in compiler/runtime tests. A differently
named program, another constant, or a result check the old runner never executed
is not by itself an additional observation. A retained accept/reject case needs
WF compilation only; these migrations do not add native builds or executions.

`Migrate` identifies the focused normative receiver. `Covered` names existing
or co-migrated observations and explains what the old source adds or fails to
observe. `Retire` explains why the source is not a useful maintained case.
Conformance IDs below resolve under `tests/conformance/cases/<id>.wf`; paths
name the actual program or implementation receiver. Intermediate revisions
leave unreviewed sources in the old runner until their dispositions are settled.

Reviewed 131 of 484 sources: 39 migrate, 91 covered, 1 retire. 353 remain to review.
